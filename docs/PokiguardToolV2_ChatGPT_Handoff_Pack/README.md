# PokiguardToolV2 — ChatGPT Handoff Pack

This pack is for **ChatGPT**, not Codex/Claude.

Purpose:

- open a fresh ChatGPT conversation at any time;
- give ChatGPT a stable project baseline;
- paste the latest completed phase result;
- have ChatGPT review it and generate the next detailed Codex/Claude prompt.

Recommended files to provide to a fresh ChatGPT chat:

1. `00_BASELINE_FOR_CHATGPT.md`
2. `02_FRESH_CHAT_STARTER.md`
3. the latest phase result using `03_PHASE_RESULT_HANDOFF_TEMPLATE.md`

Useful supporting files:

- `01_CHATGPT_PROMPT_GENERATION_PROTOCOL.md`
- `04_ROADMAP_FOR_CHATGPT.md`

The repository's newer `CURRENT_STATE.md`, `DECISIONS.md`, and phase reports always override an older external baseline.

You do NOT need to carry the original long ChatGPT conversation forward.
