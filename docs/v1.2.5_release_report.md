# PokiguardToolV2 v1.2.5

Ngày build: **2026-10-10 (Asia/Saigon)**.

Theo yêu cầu người dùng, phát hành gói sửa room recovery vừa kiểm tra dưới
phiên bản **v1.2.5**. Nhãn UI là `Tool PokiguardV2 - v1.2.5`; build script
vẫn lấy phiên bản từ `src/pokiguard_v2/version.py`.

## Phạm vi

Payload giữ nguyên so với bản sửa `v1.2.4-room-recovery-20261010`: PlayerPrefs
theo metadata Pet Puzzle, bỏ veto registry thiếu/cũ khi đủ bằng chứng thoát
shell, phục hồi đúng boss sau confirm nếu đang ở map/sảnh/room lỗi và log
`postmatch_boss_room_missing`. Chi tiết tại
[báo cáo sửa room recovery](petpuzzle_room_reentry_fix_20261010.md).

Gói cũng giữ các thay đổi boss data và Bú win guest đã có trong source đó.
Lần build này chỉ đổi phiên bản và kỳ vọng kiểm thử tương ứng; không sửa thêm
logic gameplay, thứ tự memory/capture/input hoặc bật reasoning. Phase 5B.3
vẫn tạm dừng. Gói v1.2.4 ổn định và gói sửa trước đó được giữ nguyên.
