# Local Phase 5 evidence

Native combat/UI logs, screenshots, source snapshots, per-account calibration,
activation requests/claims and extracted test binaries are retained locally.
They are excluded from Git and the distributed application ZIP.

Phase reports and closure paths describe the evidence on the operator machine.
Native review/qualification tests and preparation tools require that retained
evidence; a fresh clone does not contain or authorize a personal calibration.
Missing/incompatible UI reasoning profiles use BASIC and report the reason.

Do not manufacture native proof, reset consumed claims, or replace recorded
hashes to make an absent local fixture or a new deployment pass.
